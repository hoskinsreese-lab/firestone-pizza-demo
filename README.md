# Firestone Pizza — Hoskin's Designs portfolio concept

A responsive fictional pizza restaurant website demonstrating menu filters, pizza customization, and a local cart.

## Run it

Open `index.html` in your browser. No build tools required. External food photos and Google Fonts require internet access.

## Publish for free with GitHub Pages

1. Create a new **public** GitHub repository, e.g. `firestone-pizza-demo`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Go to **Settings > Pages > Build and deployment**, select **Deploy from a branch**, `main`, `/ (root)`, and Save.
4. Wait for the Pages URL to become active.

## Important: DEMO ONLY

- This is a fictional restaurant, with fictional menu and prices.
- Checkout intentionally does **not** accept payments or send orders.
- The cart is stored locally in the visitor's browser. It is not sent to a restaurant.
- For a real client, confirm their ordering/POS provider (Square, Toast, etc.), configure menu items and modifiers in that provider, and connect the **Order Online** CTA to the restaurant's official ordering URL. Test a real end-to-end order with the restaurant before launch.
- Do not connect a generic static payment link as a substitute for a functioning restaurant order workflow.
- Replace demo images, business details, and branding with approved client assets. External Unsplash image URLs are used for illustration; verify image licensing and reliability before commercial use.
- Use client-owned ordering accounts and domains, and agree on maintenance responsibilities.
