# Firestone Pizza — refreshed complete website

Portfolio concept for Hoskin's Designs. Fictional restaurant; no real orders or payments.

## Files to upload to GitHub

Upload ALL FOUR files directly into the root of your `firestone-pizza-demo` repository:

- `index.html`
- `styles.css`
- `script.js`
- `pizza-feature.svg`

The **WE DON'T DO AVERAGE** section now uses a pizza photo URL instead of the unrelated office image. A local pizza illustration (`pizza-feature.svg`) automatically appears if the external photo cannot load.

## Publishing

GitHub: repository → Add file → Upload files. Select all four files from this folder and commit. Keep Pages configured as `main` / `(root)`. Wait for deployment, then hard-refresh the site (Ctrl+Shift+R).

Do not upload the ZIP file itself to GitHub Pages; unzip first.
